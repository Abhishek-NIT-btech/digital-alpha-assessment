# AI Usage

AI assistance was used during development of this assessment to help with implementation, debugging, documentation, and verification.

## Areas where AI assistance was used

- Reviewing the assessment requirements and identifying missing functionality.
- Suggesting React component and state-management approaches.
- Helping implement transaction filters, pagination, sorting, and transaction details.
- Helping design the monthly spending analytics.
- Helping troubleshoot FastAPI, SQLAlchemy, PostgreSQL, CORS, and frontend API integration issues.
- Reviewing test and build errors and suggesting fixes.
- Helping prepare project documentation such as assumptions and technical decisions.

## Human Verification

All generated or suggested code was reviewed and tested locally before inclusion in the project.

The following checks were used during development:

- Python syntax compilation with `py_compile`
- Backend database connectivity tests
- FastAPI endpoint testing with `curl`
- PostgreSQL verification
- Frontend production build with Vite
- Manual verification of dashboard functionality

AI assistance was used as a development aid; final implementation decisions, testing, and project submission were performed by the developer.
