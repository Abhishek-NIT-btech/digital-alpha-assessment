Full-stack transaction dashboard with analytics and rewards, built with React, Vite, FastAPI, and PostgreSQL.

## Features

- Transaction dashboard with summary statistics
- Transaction listing with pagination
- Search by merchant
- Filter by category
- Filter by transaction status
- Filter by payment method
- Sort transactions by ID, date, amount, or merchant
- Transaction detail endpoint
- Spending by category analytics
- Payment method analytics
- Top merchant analytics
- Rewards catalogue
- Reward coin balance
- Reward redemption functionality
- PostgreSQL-backed transaction data
- REST API with validation
- Responsive frontend interface
